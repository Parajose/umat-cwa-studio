# UMaT CWA Studio 0.1.0 — Windows Preview

Download `UMaT-CWA-Studio-0.1.0-windows-x64.zip`, extract the whole folder and double-click `UMaT_CWA_Studio.exe`. Windows 10/11 x64 is required. No compiler or database server is required to try the portable app.

Features: navy-and-gold interface, OOP C++ models, course input clearing, saved student/course tables, credit-weighted averages, semester summaries, search, editing and CSV export. Records stay local to your Windows user.

The release pipeline compiles on Windows, runs the model/SQLite checks and exercises the GUI through student entry, course clearing, save, database view and restart persistence. The `.sha256` file allows verification with `Get-FileHash`.

This is an unsigned educational preview. High-DPI layouts and all supported Windows versions still need broader manual testing. Existing data is unencrypted; repeat-course/graduation policies and online synchronisation are not implemented. This is not official university records software.

Use fictional data to try it. Please report issues with Windows version, display scaling, reproduction steps, expected behaviour and actual behaviour; hide personal student details in screenshots.
